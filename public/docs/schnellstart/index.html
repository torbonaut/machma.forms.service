Schnellstart

In fünf Schritten vom Formular zur ersten Einsendung.

  1. Zugang anfragen

    Über das Formular auf der Startseite. Wir legen deine Seite an: Domain(s), Absendername und die Empfängeradressen.

  2. Formular beschreiben

    Ein Formular ist eine JSON-Datei mit Feldern, Labels und optional einem Mail-Template. Am schnellsten schickst du uns den Link auf dein bestehendes Formular – unser KI-Skill erzeugt daraus eine geprüfte Formular-JSON. Alle Optionen: Formular-JSON.

    {
  "id": "kontakt",
  "version": 1,
  "recipient": "rezeption",
  "fields": [
    { "name": "name", "type": "text", "required": true, "label": { "de": "Name", "en": "Name" } },
    { "name": "email", "type": "email", "required": true, "replyTo": true, "label": { "de": "E-Mail", "en": "Email" } },
    { "name": "nachricht", "type": "textarea", "required": true, "label": { "de": "Nachricht", "en": "Message" } },
    { "name": "datenschutz", "type": "consent", "required": true,
      "label": { "de": "Ich akzeptiere die Datenschutzerklärung", "en": "I accept the privacy policy" } }
  ]
}

  3. Einbinden

    An der Stelle, an der das Formular erscheinen soll:

    <div class="mf-slot" data-machma-form="beispielhotel/kontakt" data-locale="de"></div>
<noscript>Bitte JavaScript aktivieren oder anrufen: +43 …</noscript>
<script src="https://forms.machma.app/v1/embed.js?v=1" defer></script>

<style>
  .mf-slot { min-height: 640px; }   /* Höhe an das Formular anpassen */
</style>

    Hat deine Seite eine Content-Security-Policy, erlaube https://forms.machma.app unter script-src und connect-src. Mehr dazu unter Einbindung.

  4. Absender freigeben

    Alle Mails kommen von formulare@machma.app. Die Empfänger nehmen diese Adresse in ihr Adressbuch auf, damit nichts im Spam landet – siehe Mailversand.

  5. Testen

    Schick das Formular einmal selbst ab. Im Dashboard siehst du jede Einsendung mit Status (versendet, Spam, Fehler) – ohne Inhalte.
