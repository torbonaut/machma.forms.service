Mailversand

Wie Mails ankommen – und was Empfänger tun können, damit sie nicht im Spam landen.

Absender

Alle Mails kommen von formulare@machma.app, mit dem Anzeigenamen der Kundenseite, z. B. „Hotel Seeblick via machma forms“. Reply-To ist die Adresse aus dem Formular – ein Klick auf „Antworten“ geht also direkt an die Person, die das Formular abgeschickt hat. Kunden müssen nichts einrichten: kein SMTP-Zugang, keine DNS-Einträge.

Die Danke-Mail (Autoresponder) geht an die Absenderadresse aus dem Formular; ihre Antwortadresse ist die Adresse des Kunden. Pro Empfängeradresse gehen höchstens drei Danke-Mails am Tag hinaus.

Für formulare@machma.app sind SPF, DKIM und DMARC eingerichtet, damit die Mails als echt erkannt werden.

Zustellung sicherstellen

Nimm formulare@machma.app in dein Adressbuch bzw. die Liste sicherer Absender auf:

Outlook

  • Outlook im Web / neues Outlook: Einstellungen → E-Mail → Junk-E-Mail → „Sichere Absender und Domänen“ → Hinzufügen → formulare@machma.app → Speichern.
  • Outlook für Windows (klassisch): Start → Junk-E-Mail → Junk-E-Mail-Optionen → Sichere Absender → Hinzufügen.

Gmail

  • Zahnrad → Alle Einstellungen aufrufen → Filter und blockierte Adressen → Neuen Filter erstellen.
  • Bei „Von“ formulare@machma.app eintragen → Filter erstellen → „Nie als Spam einstufen“ anhaken → Filter erstellen.

Apple Mail

  • Eine Mail von machma forms öffnen, auf den Absender klicken → „Zu Kontakten hinzufügen“.
  • Unter iCloud-Mail zusätzlich: Mail → Einstellungen → Regeln, falls eine Regel Mails verschiebt.

Bei eigenen Mailservern oder Spamfiltern (z. B. in Firmen) bitte die IT, formulare@machma.app freizugeben.

Testen

  1. Schick das Formular auf deiner Seite einmal selbst ab, mit deiner eigenen Adresse im E-Mail-Feld.
  2. Im Dashboard sollte die Einsendung als „versendet“ erscheinen. Als Admin gibt es dort zusätzlich die Testeinsendung und einen SMTP-Test.
  3. Landet die Mail im Spam: als „Kein Spam“ markieren und den Absender wie oben freigeben.
  4. Kommt gar nichts an: Spam- und Quarantäne-Ordner prüfen (auch im Admin-Bereich des Mailanbieters), Tippfehler in der Empfängeradresse ausschließen, uns kontaktieren. Im Dashboard steht bei Fehlern der Grund, z. B. smtp_connect.

Warum keine eigene Absenderdomain?

Ein Postfach, eine DNS-Konfiguration, kein SMTP-Zugang von Kunden. Das hält die Zustellbarkeit hoch und das Setup einfach.
