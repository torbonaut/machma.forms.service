Eigenes HTML

Das Formular gibt es schon – mit eigenen Texten, eigenem Layout und eigenem Design. machma forms übernimmt nur Spamschutz, Prüfung und Versand.

So funktioniert’s

    
    
      
  • Das <form> bekommt nur data-machma-form="seite/formular".
    • 
      
  • Die name-Attribute müssen zu den Feldnamen in der Formular-JSON passen. Texte, Reihenfolge, Layout und CSS sind frei.
    • 
      
  • Geprüft wird immer auf dem Server nach der JSON: Probier, ohne Angaben abzuschicken – die Fehler erscheinen unter dem jeweiligen Feld.
    • 
      
  • Honeypot und ALTCHA fügt das Skript selbst unsichtbar hinzu. Kein action, keine Empfängeradresse im HTML.
    • 
      
  • Mit data-redirect-url="/danke" geht es nach dem Senden auf eine eigene Danke-Seite.
    • 
    

    
Einbindung

    
<form class="own-form" data-machma-form="demo/kontakt" data-locale="de"
      data-success-message="Danke! (Demo – es wurde nichts verschickt.)">
  <div class="own-row">
    <label>Wie heißen Sie? <input name="name" autocomplete="name"></label>
    <label>Ihre E-Mail-Adresse <input name="email" type="email" autocomplete="email"></label>
  </div>
  <div class="own-row">
    <label>Anreise (optional) <input name="anreise" type="date"></label>
    <label>Personen <input name="personen" type="number" min="1" max="12"></label>
  </div>
  <label>Worum geht es?
    <select name="thema">
      <option value="">Bitte auswählen</option>
      <option value="zimmer">Ich möchte ein Zimmer anfragen</option>
      <option value="sonstiges">Etwas anderes</option>
    </select>
  </label>
  <label>Ihre Nachricht <textarea name="nachricht" rows="5"></textarea></label>
  <label class="own-check"><input type="checkbox" name="datenschutz"> Ich habe die Datenschutzerklärung gelesen.</label>
  <button type="submit" class="own-button">Anfrage senden →</button>
</form>

<script src="https://forms.machma.app/v1/embed.js?v=1" defer></script>

    
Dieselbe Formular-JSON wie im Kontakt-Beispiel, dort automatisch gerendert.
