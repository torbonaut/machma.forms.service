Formulare für jede Website. Ohne Drittanbieter.

machma forms nimmt Formulare von beliebigen Websites entgegen, prüft sie und verschickt sie per Mail. Selbst gehostet bei netcup, ohne Cookies, ohne gespeicherte Inhalte – und kostenlos.

Was der Service kann

Formulare als JSON

Felder, Pflichtfelder, Längen, Optionen, Labels auf Deutsch und Englisch – an einer Stelle beschrieben.

Eine Zeile Einbindung

Ein Skript für Astro, reines HTML oder WordPress. Rendert das Formular oder übernimmt dein eigenes HTML.

Mail mit CC/BCC

Zustellung an feste Empfänger, „Antworten“ geht direkt an den Absender, optional eine Danke-Mail.

Spamschutz ohne Rätsel

ALTCHA rechnet im Browser eine kleine Aufgabe – kein Bilderrätsel, kein Tracking. Dazu Honeypot, Mindestzeit, Rate-Limit.

Dashboard

Einsendungen pro Tag, Spam-Anteil, Fehler – jede Kundin sieht nur ihre eigenen Seiten.

Open Source

Reines PHP unter MIT-Lizenz. Läuft auf einfachem Webspace, ohne Container oder Queue.

Datenschutz als Voreinstellung

  • Keine Drittanbieter: kein reCAPTCHA, keine fremden Skripte, keine CDN.
  • Keine Cookies auf der Website deiner Kundinnen und Kunden.
  • Keine gespeicherten Inhalte: Einsendungen werden zugestellt, nie abgelegt.
  • Nur Metadaten im Log (Zeit, Status, täglich wechselnder IP-Hash), 90 Tage.
  • Nur an Adressen des Kunden: kein Wert aus dem Browser bestimmt, wohin eine Mail geht.
